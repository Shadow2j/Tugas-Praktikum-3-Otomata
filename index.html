Apa itu PDA?

Pushdown Automaton (PDA) adalah mesin otomata yang memiliki stack sebagai memori tambahan. PDA lebih kuat dari Finite Automata karena dapat mengenali bahasa context-free.

Definisi Formal PDA

PDA didefinisikan sebagai 7-tuple: M = (Q, Σ, Γ, δ, q₀, Z₀, F)

  • Q = Himpunan state
  • Σ = Alfabet input
  • Γ = Alfabet stack
  • δ = Fungsi transisi: Q × (Σ ∪ {ε}) × Γ → Q × Γ*
  • q₀ = State awal
  • Z₀ = Simbol awal stack
  • F = Himpunan state penerima

Cara Menggunakan

  1. Masukkan daftar states, alfabet input, dan alfabet stack
  2. Pilih state awal dan simbol awal stack
  3. Tentukan state penerima (accept states)
  4. Tambahkan fungsi transisi satu per satu
  5. Masukkan string yang ingin diuji
  6. Klik "Jalankan" untuk melihat hasil

Transisi

Format transisi: δ(state, input, stackTop) = (nextState, pushStack)

  • Gunakan ε untuk transisi epsilon (tanpa membaca input)
  • Pada kolom "Push Stack", masukkan simbol-simbol yang akan dipush (dari kiri ke kanan, simbol paling kiri akan berada di top stack)
  • Gunakan ε pada Push Stack untuk melakukan pop tanpa push (menghapus top stack)

Mode Penerimaan

  • Final State: String diterima jika PDA berakhir di state penerima setelah membaca seluruh input
  • Empty Stack: String diterima jika stack kosong setelah membaca seluruh input
  • Keduanya: String diterima jika salah satu kondisi terpenuhi
